개인정보처리방침

오토니(OTONI, 이하 “회사”)는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

1. 처리하는 개인정보 항목과 목적

회사는 업무에 꼭 필요한 최소한의 개인정보만 처리합니다.

구분항목목적
이메일·전화 문의이름(또는 회사명), 이메일 주소 또는 전화번호, 문의 내용문의 확인 및 답변
OTONI FILE SEND 이용아래 2항의 Google 사용자 데이터대용량 파일을 Google Drive에 올리고 공유 링크를 만드는 기능 제공

이 홈페이지는 회원가입이 없으며, 쿠키·방문 분석 도구·광고 추적 도구를 사용하지 않습니다.

2. OTONI FILE SEND의 Google 사용자 데이터 처리

OTONI FILE SEND는 이용자의 PC에서 실행되는 메일 첨부 도우미 프로그램입니다. 이용자가 Google 계정으로 로그인해 권한을 허락한 경우에만 다음과 같이 Google 사용자 데이터에 접근합니다.

  • 요청 권한: Google Drive 파일 권한(drive.file) — 이 앱이 만들거나 이용자가 이 앱으로 연 파일에만 접근하며, 이용자의 다른 Drive 파일은 보거나 바꾸지 않습니다.
  • 사용 방법: 이용자가 고른 첨부 파일을 이용자 본인의 Google Drive에 올리고, 메일에 넣을 공유 링크를 만드는 데에만 사용합니다.
  • 저장: 로그인 토큰은 이용자 PC에만 Windows 암호화(DPAPI)로 저장되며, 회사 서버로 보내지 않습니다. 회사는 이용자의 파일·메일 내용·Google 데이터를 수집하거나 보관하지 않습니다.
  • 공유·판매 금지: Google 사용자 데이터를 제3자에게 제공·판매하지 않으며, 광고나 AI 모델 학습에 사용하지 않습니다.
  • 연결 해제: 언제든지 Google 계정 → 보안 → “서드파티 앱 및 서비스”에서 OTONI FILE SEND의 접근 권한을 삭제할 수 있습니다. 권한을 삭제하면 PC에 남은 토큰으로도 더 이상 접근할 수 없습니다.

OTONI FILE SEND가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use(제한적 사용) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

3. 보유 및 이용 기간

문의 과정에서 받은 개인정보는 답변이 끝나면 지체 없이 파기합니다. 다만 거래가 이어져 관계 법령(전자상거래법·상법·국세기본법 등)에 따라 보존해야 하는 정보는 그 기간 동안 보관합니다.

4. 제3자 제공 및 처리 위탁

회사는 이용자의 개인정보를 제3자에게 제공하거나 외부에 처리를 위탁하지 않습니다. 법령에 특별한 규정이 있는 경우는 예외로 합니다.

5. 파기 절차 및 방법

보유 기간이 끝난 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제하고, 종이 문서는 분쇄하거나 소각합니다.

6. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보 열람·정정·삭제·처리 정지를 요구할 수 있습니다. 아래 이메일로 요청하시면 지체 없이 처리합니다.

7. 안전성 확보 조치

회사는 개인정보에 대한 접근 권한을 대표자로 제한하고, 저장 자료는 암호를 걸어 보관하는 등 필요한 보호 조치를 하고 있습니다.
