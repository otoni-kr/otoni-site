소프트웨어 개발 중

전장 설계와 현장 Setup을 위한 설계 통합 자동화 시스템을 개발합니다.

개발 로드맵

개발 이유 및 목표

전장 설계는 회로도부터 인증 검토까지 많은 시간을 들여 작업해야 합니다. 실무자가 반복 작업과 확인·검토, 자료 수집까지 직접 해야 하기 때문입니다.

오토니는 설계 데이터 하나로 도면과 문서가 함께 만들어지며, 현장에서도 이를 쉽게 접근할 수 있는 전장 설계 통합 자동화 시스템을 개발하는 것이 목표입니다.

개발 방향

오토니는 실무에서 직접 쓰는 도구에서 출발해, 데이터를 쌓고 자동화를 넓혀 가며 하나의 시스템으로 이어 가고 있습니다.

각 단계의 아이디어와 개발 방향은 이미 구체적으로 정리를 마친 상태입니다. 다만 권리 보호를 위해 구체적인 내용은 지금 모두 공개할 수 없는 점, 양해 부탁드립니다.

오토니는 위 과정을 거쳐 최종 목표를 완성해 가겠습니다. 많은 관심과 성원 부탁드립니다.

  1. 1단계 · 현재60%

    실무형 CAD·Excel 설계 자동화 도구

    설계자가 실무에서 편리하게 사용할 수 있도록 개발 중입니다.

  2. 2단계 

    CAD·Excel 블록 자동 생성 도구

    부품 블록을 자동으로 만들고, 부품·규격 데이터를 하나로 모아 설계 데이터 기반으로 사용할 수 있도록 개발할 예정입니다.

  3. 3단계 

    CAD·Excel 자동 설계 도구

    회로도부터 배치도, 타공도, 하네스·BOM 등의 자료를 자동으로 생성하여 사용할 수 있도록 개발할 예정입니다.

  4. 4단계 

    EPLAN 변환 도구

    CAD에서 설계한 파일을 EPLAN으로 변환해, 단순한 그림이 아니라 EPLAN 기능을 그대로 사용할 수 있도록 개발할 예정입니다.

  5. 5단계 · 최종 목표 

    설계 통합 자동화 시스템

    CAD·Excel 및 기타 소프트웨어를 활용해, 현장에서 필요한 전장 자료(도면·데이터, I/O 체크 등)에 쉽게 접근할 수 있도록 개발할 예정입니다.

캐드 전장 설계 자동화

OtoCompass는 보안상 일부 화면만 공개하고 있습니다. 양해 부탁드립니다.

특허 등 권리 보호 절차를 마친 뒤 더 자세히 공개하겠습니다.

AutoCAD 2024에서 개발하고 작동을 확인했으며, 앞으로는 주 개발 환경을 AutoCAD에서 BricsCAD로 우선 옮길 계획입니다.

엑셀 데이터 정리 및 캐드 설계 통합 자동화

현재 Excel 2024에서 작동을 확인했으며, 다른 버전은 시험 중입니다.

버전에 따라 일부 기능이 작동하지 않을 수 있습니다. Mac·웹·모바일 Excel은 지원하지 않습니다.

Windows 10·11 PC용 Microsoft Excel 2016 이상(Microsoft 365 포함)을 대상으로 개발하고 있습니다.
