소프트웨어 개발 중

전장 설계와 현장 Setup을 위한 설계 통합 자동화 시스템을 개발합니다.

개발 로드맵

왜 만드나

전장 설계는 회로도·배치도·타공도·하네스·BOM·인증 검토가 서로 맞물려 있지만, 지금은 대부분 사람이 하나하나 옮기고 맞춥니다.

OTONI는 설계 데이터 하나로 도면(CAD)과 문서(Excel)가 함께 만들어지는 전장 설계 통합 자동화 시스템을 개발합니다.

  1. 회로도
  2. 배치도
  3. 타공도
  4. 하네스·BOM
  5. 인증 검토
  6. 현장

지금 — 1단계 실무 도구

현장 경험을 바탕으로 만든 CAD·Excel 도구를 실제 프로젝트에 적용하며 다듬고 있습니다.

부품 카탈로그와 인증 규격(UL·CE·SCCR 등)을 데이터로 정리하는 작업도 함께 진행 중입니다.

앞으로

2단계 공통 코어 — CAD와 Excel이 같은 데이터를 쓰는 하나의 기반

3단계 자동 설계 — 블록 자동 생성 → 회로도 → 배치도 → 타공도 → 하네스·BOM → 인증 검토·부품 자동 선정 → PLC I/O 도면까지 한 흐름으로.

EPLAN 도면을 CAD로 변환해, EPLAN에서 더 이상 설계하지 않아도 될 수준까지 구현합니다.

(단순한 선 변환이 아니라, EPLAN에서도 EPLAN 기능을 그대로 쓸 수 있는 변환)

4단계 현장 — 최종 목표 — 설계 자료를 국내외 Setup 현장에서 바로 찾아 쓰고 활용할 수 있게.

아이디어와 단계별 개발 방향은 구체적으로 정리를 마쳤으며, 개발하면서 보완해 갑니다.

CAD

캐드 전장 설계 자동화

CAD 도구는 보안상 일부 화면만 공개하고 있습니다. 양해 부탁드립니다.

특허 등 권리 보호 절차를 마친 뒤 더 자세히 공개하겠습니다.

AutoCAD 2024에서 작동을 확인했으며, 다른 버전은 시험 중입니다.

EXCEL

엑셀 데이터 정리 및 캐드 설계 통합 자동화

현재 Excel 2024에서 작동을 확인했으며, 다른 버전은 시험 중입니다.

버전에 따라 일부 기능이 작동하지 않을 수 있습니다. Mac·웹·모바일 Excel은 지원하지 않습니다.

Windows 10·11 PC용 Microsoft Excel 2016 이상(Microsoft 365 포함)을 대상으로 개발하고 있습니다.

제품

현재 판매하지 않습니다.
